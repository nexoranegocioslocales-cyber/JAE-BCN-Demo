# Demo JAE BCN preparada por Nexora

Web estática con 16 páginas, menú de servicios desplegable, buscador, carrusel manual, animaciones, contacto y mapa bajo demanda.

## Demo publicada

https://nexoranegocioslocales-cyber.github.io/JAE-BCN-Demo/

## Subir a GitHub Pages

1. Descomprime el ZIP.
2. Crea un repositorio, por ejemplo JAE-BCN-Demo.
3. Sube el contenido de la carpeta descomprimida a la raíz del repositorio. index.html debe quedar en la raíz, no dentro de una carpeta adicional.
4. En el repositorio abre Settings > Pages.
5. En Source selecciona Deploy from a branch.
6. Selecciona main y /(root), y pulsa Save.
7. Espera a que GitHub indique la URL publicada.

No subas el ZIP sin descomprimir: GitHub Pages necesita los archivos.
No se requiere npm, WordPress ni servidor PHP. Los enlaces son relativos y sirven en un repositorio de proyecto.

Documentación oficial:
https://docs.github.com/es/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Archivos principales

- index.html: portada.
- empresa.html: información de la empresa.
- servicios.html: todos los servicios.
- antenas.html, porteros-electronicos.html, videoporteros.html, videovigilancia.html, domotica.html, otros-servicios.html: servicios.
- noticias.html, dividendo-digital.html, tdt.html: archivo de noticias.
- contacto.html: consulta de demostración y mapa.
- aviso-legal.html, privacidad.html, cookies.html: información de la demo.
- style.css: diseño y animaciones.
- app.js: menú, buscador, carrusel, formularios y animaciones.
- logo.png, instalacion.jpg, cctv.jpg: recursos recuperados de la web original.
- .nojekyll: publicación estática sin procesamiento Jekyll.

## Antes de publicar como web oficial

El formulario valida nombre, correo y consulta; genera un resumen, permite copiarlo o descargarlo y enlaza al contacto oficial de JAE. No transmite los datos desde esta demo.
El mapa usa Google Maps y se carga al pulsar el botón.
La web antigua bloqueó la recuperación de algunas páginas: los textos de servicios son propuestas y ciertos artículos enlazan al original.
JAE debe revisar datos, compromisos, textos legales y autorización de uso de imágenes.
Las fechas de noticias son históricas; no se muestran como novedades actuales.
El aviso de preferencias guarda únicamente una elección local. No activa analítica.
No incluye credenciales, acceso a cuentas ni cambios de DNS.
No añadas jaebcn.com como dominio personalizado hasta tener autorización y revisar el correo del dominio.
